## Три воспроизводимых кейса

Подготовка: команды из `apps/web/README.md`, backend `ASTANA_MODE=fixture`, frontend
`ASTANA_ALLOW_FIXTURES=true`. Баннер synthetic должен оставаться виден. Координаты
демо — `51.090 / 71.420`. Для фиксированного показа начало `2026-10-19 12:00`
Asia/Almaty; для live после интеграции выбрать актуальное время и проверенные места.

### Кейс 1: есть 90 минут

Запрос «Прогулка без спешки», 90 минут, return включён, без required. Три
синтетических места foundation дают самостоятельные варианты. Открыть источники.
Сказать: «Это проверка пути пользователя и контрактов. Синтетический источник не
подтверждает существование реального места». Выбрать ручную точку, не запрашивая
геолокацию на сцене. Объяснить, почему неизвестная доступность не стала «нет».

### Кейс 2: две остановки с возвращением

Добавить первые две карточки. Переставить явной кнопкой и рассчитать маршрут.
Показать полный порядок, посещения, дорогу и возврат. В fixture геометрия null:
карта отображает точки с пояснением приблизительности, без линии пешеходного пути.
Уменьшить бюджет до 1 минуты и повторить — no_match, обе остановки сохранены.

### Кейс 3: требуется подтверждённая доступность

Вернуть 90 минут, выбрать «Доступно на коляске → Обязательно», выполнить подбор.
Ожидается no_match: источник не подтверждает это свойство. Обязательное условие
не меняется само. Пользователь может самостоятельно изменить его на «Желательно»
и получить альтернативы с предупреждением; демонстратор явно делает это действие.

## Рассказ об ИИ без ложных обещаний

«Мы создаём продукт вокруг данных и проверяемых ограничений. Поиск даёт кандидатов;
детерминированный код проверяет факты, evidence, весь бюджет и выбранные остановки.
OpenAI/NVIDIA adapters — внешний inference для выбора подтверждённых оснований.
Это не наша обученная модель. Текущий генератор не читает сырой query и не извлекает
из него обязательные условия. Их мы явно задаём в форме. При отказе модели
показывается объяснение по данным каталога, а ошибка и ограничения остаются видны».

Для будущего обучения использовать `docs/ai/TRAINING.md`: сначала разрешённые
данные, baseline и held-out eval, затем подходящий retriever/reranker или отдельный
intent-компонент. RAG не равен изменению весов. Ключ inference не равен доступу к GPU.

## Резервный показ

1. Нет интернета: fixture API и `ASTANA_MAP_PROVIDER=none`. Показать каталог,
   источники как сохранённые references, точки и приблизительность. Не заявлять live.
2. Нет WebGL: форма, карточки, источники и перестановка остановок остаются рабочими.
3. Нет backend: открыть заранее сохранённые **реальные скриншоты тестового прогона**
   и отчёт `playwright-report`; назвать режим и дату. Это запись, а не текущий ответ.
4. Нет inference: штатный deterministic fallback, никаких красивых выдуманных фактов.

Большие изображения, видео и PowerPoint в Git не нужны. Скриншоты сохраняются
через `ASTANA_SCREENSHOT_DIR`, материалы доступны как артефакты локального/CI
прогона. Публикация видео или YouTube не входит в этот PR.
