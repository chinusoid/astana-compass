# Реальные сведения на карте и пешие маршруты

Для небольшой публичной проверки доступны источники без ключей:

- `ASTANA_MAP_LOOKUP_ENABLED=true`, `ASTANA_MAP_LOOKUP_PROVIDER=nominatim`:
  POST `/v1/map-features` принимает только `location` и `locale` по canonical
  schema. Координата явно нажатой точки отправляется на Nominatim. Сервер
  ограничивает область Астаной, округляет координаты запроса до 4 знаков,
  кэширует публичный ответ сутки, допускает 60 новых областей/сутки, интервал
  5 секунд, 9 MB полученных ответов/сутки. Ограничения общие для процесса;
  перезапуск их сбрасывает. Для оценки запускайте один процесс.
- `ROUTING_PROVIDER=osrm_public`: FOSSGIS OSRM с foot-профилем, полная геометрия
  и последовательность остановок. Запросы не чаще одного в 1.05 секунды,
  до 10 в минуту/600 в сутки; кэш маршрутов 5 минут. Координаты начала и
  остановок уходят провайдеру. Профиль driving не используется.

Нажатие на здание не гарантирует, что у OSM есть его описание. Ответ явно
различает попадание в контур и найденный объект рядом; отсутствующие факты
не дополняются догадками. В карточке есть ссылка на объект OSM и время
получения, которое не означает дату проверки каждого свойства.

При отказе маршрутизатора действует `ASTANA_ROUTE_ALLOW_APPROXIMATE`.
При true API может вернуть оценку с `geometry=null`; UI не рисует её как
пеший маршрут. При false ошибка остаётся явной. Snap к сети ограничен 100 м;
входы, текущие ограждения и закрытия не подтверждены.

Эти публичные сервисы не дают SLA. Для роста трафика замените Nominatim через
серверный `ASTANA_MAP_LOOKUP_URL=https://.../reverse` на собственный или
договорной совместимый сервис, а маршруты — на уже поддержанный
`openrouteservice` с серверным `ROUTING_API_KEY`. Пустой override использует
стандартный endpoint. В качестве альтернативы поддержан `overpass`, но
публичные экземпляры при проверке отвечали ошибками; он не выбран по умолчанию.

Атрибуция OSM присутствует в ответах и UI. Условия источников:
[Nominatim](https://operations.osmfoundation.org/policies/nominatim/),
[FOSSGIS](https://routing.openstreetmap.de/about.html),
[ODbL](https://www.openstreetmap.org/copyright).

геометрию к Байтереку и обратно; Nominatim вернул объект

Это проверка доступности на момент запроса, а не гарантия работы публичных
серверов или полноты карты. CI использует записанные тестовые ответы.
