# 2ГИС: сведения об организациях по запросу

`TwoGisPlacesService` дополняет карточку выбранного места отдельными кандидатами
2ГИС. Это запрос к справочнику, а не импорт новой городской базы. Совпадение
названия и координат не доказывает тождество филиала: ответ всегда помечен
`match: nearby`, содержит собственное имя, адрес, расстояние и ссылку на филиал.
Часы и описания кандидата не записываются в `Place.facts`, не подменяют сведения
OSM и не передаются в LLM.

## Настройка

Ключ `TWOGIS_API_KEY` хранится только в окружении Python API (Render). Нужен
доступ к Places API; доступ к контактам не запрашивается. В production приложение
создаёт один экземпляр сервиса. Без ключа или при выключенном сервисе запрос
завершается безопасной ошибкой доступности, сохраняя основной каталог.

Публичная граница приложения — `POST /v1/place-directory` с `place_id` и `locale`.
API получает место из собственного репозитория и вызывает `search(place, locale)`;
произвольные имя, URL или координаты из тела запроса провайдеру не пересылаются.
Ответ использует существующий `MapFeatureResponse`. Все успешные и ошибочные
ответы этого endpoint должны отправляться с `Cache-Control: no-store`.

## Объём и защита запросов

- Один GET к `https://catalog.api.2gis.com/3.0/items`, без обхода страниц и повторов.
- `q` — имя канонического места; `type=branch`, `point=lon,lat`, `radius=300`,
  `page_size=5`. `location` не заменяет географическое ограничение.
- Поля: `items.point,items.rubrics,items.schedule,items.schedule_special,items.description,items.name_ex`.
- Локали: `ru_KZ` и `kk_KZ`; для английского интерфейса используется `ru_KZ`,
  потому что `en_KZ` не перечислена среди поддерживаемых локалей. Перевод не выдумывается.
- Общий deadline 5 секунд включает ожидание блокировки; транспорт ограничен
  256 000 байтами и нулём повторов. На один процесс: 6 попыток за скользящую
  минуту, 100 за скользящие сутки, не чаще одной попытки за 5 секунд.
- HTTP-ошибки и `meta.code` проверяются отдельно. `meta.code=404` означает пустую
  выдачу; `403` — недоступность; `429` — пауза не менее 60 секунд. Другие сбои
  не выдаются за отсутствие организаций.

Ограничения процесса сбрасываются после перезапуска; для нескольких экземпляров
потребуется общий счётчик попыток без хранения содержимого ответов. Лимит самого
ключа дополнительно настраивается в кабинете провайдера.

## Как понимать часы и описания

Каждый день недели и каждая особая дата выводятся отдельно, в местном времени
организации. Ночные интервалы сохраняют пометку следующего дня; `00:00–24:00`
сохраняется целиком. Период действия и примечания расписания имеют свои подписи.
Сначала показываются ближайшие будущие особые даты, затем недавние прошлые;
при ограничении списка выводится явное примечание о неполноте.
Отсутствующие или некорректные часы не означают «закрыто». Особая дата с пустыми
часами обозначается как «Время не указано». Текущий статус «открыто» и открытие
на момент прибытия по этим данным не вычисляются.

`items.description` документировано как описание геообъекта и может отсутствовать
у организации. `name_ex.description` — часть имени (например «Склад»), поэтому
не используется как развёрнутое описание. Категория берётся из рубрики либо
`name_ex.extension`. Разметка описания удаляется, активные блоки отбрасываются,
текст ограничен 2000 символами и отображается как обычный текст.

## Хранение и атрибуция

Адаптер не сохраняет ответы на диск, в БД или кэш; не журналирует тело ответа,
ключ, URL запроса, имя или координаты. Диагностика содержит только фиксированную
категорию, безопасный код и HTTP/`meta` статус. Для тестов используются исключительно
синтетические данные.

При показе результата UI должен отображать ссылку [2ГИС](https://dev.2gis.ru)
и ссылку на соответствующий филиал. После закрытия карточки результат не должен
попадать в локальное долговременное хранилище или выгрузку каталога.

Официальные источники, проверены 20 октября 2026:

- [Places API: параметры, поля и схема ответа](https://docs.2gis.com/api/search/places/reference/3.0/items).
- [Примеры географического ограничения](https://docs.2gis.com/api/search/places/examples/georestriction).
- [Оферта WebAPI](https://law.2gis.ru/offer-license-agreement-webapi): п. 3.1 не предусматривает
  кэширование; п. 2.10 требует атрибуцию 2ГИС со ссылкой на правообладателя.

## Проверка без внешнего API

`tests/integration/test_twogis_places.py` проверяет синтетические ответы, фильтрацию
чужих филиалов, scoped/overnight/special hours, очистку HTML, ограничение размеров,
embedded `meta.code`, отсутствие ключей в диагностике, ограничения частоты,
отмену и deadline включая очередь. Эти проверки не доказывают работоспособность
сохранённого ключа; её нужно подтвердить одним явным запросом через приложение
после публикации, не сохраняя ответ провайдера.
