# Astana Compass

Городской ИИ-помощник для Астаны: рекомендации с источниками, прогулки под доступное время и ответы RU / KK / EN.

**Текущий результат:** работающий backend foundation с общими контрактами, рекомендациями, выбранным маршрутом, OpenAI/NVIDIA adapters и автоматическими offline-тестами. Режим по умолчанию использует **синтетические данные**. Модуль команды 02 подключён: расписания с доказательствами, адаптер пеших маршрутов ORS и внутренний модуль погоды. Реальный сбор POI, полноценный поиск и интерфейс ещё ожидают интеграции. Обученная собственная модель и публичный deployment пока отсутствуют.

## Запуск

Установите [uv](https://docs.astral.sh/uv/getting-started/installation/), затем из корня:

```sh
uv sync --locked
uv run uvicorn astana_api.app:create_app --factory --host 127.0.0.1 --port 8000 --no-access-log
```

Откройте **`http://127.0.0.1:8000/sandbox`**: это тестовый экран backend с готовыми сценариями, выбором остановок, расчётом маршрута и просмотром JSON. Полноценный пользовательский интерфейс создаёт команда 03. В `http://127.0.0.1:8000/docs` доступны примеры запросов и **Try it out → Execute**. `GET /v1/health/ready` проверяет готовность. Если порт занят, замените `8000` на `18080` в команде и адресе.

[Инструкция по тестированию и ожидаемые результаты](docs/operations/TESTING.md). Быстрая проверка работающего сервера:

```sh
uv run python scripts/smoke.py --base-url http://127.0.0.1:8000
```

`.env.example` содержит только имена настроек; экспортируйте свои значения в окружение процесса. Не публикуйте ключи в чатах, PR или frontend.

```sh
uv run pytest
uv run python verify_contracts.py
uv run python scripts/generate_contracts.py --check
uv run ruff check .
```

Docker и CI: [инфраструктура](infra/), [операции](docs/operations/).

## Три основных агента

Передайте каждому отдельный файл целиком. Каждый агент может привлекать своих subagents внутри своей области.

| Команда | Полное задание | Результат |
|---|---|---|
| 01 | [Данные и поиск](TEAM-01-DATA-SEARCH.md) | Автосбор реальных POI, provenance, hybrid retrieval, embeddings/reranking, датасет |
| 02 | [Контекст и маршруты](TEAM-02-CONTEXT-ROUTES.md) | Пешие маршруты, время, расписания, погода, честные unknown/fallback |
| 03 | [Интерфейс и UX](TEAM-03-FRONTEND-UX.md) | Next.js, карта, RU/KK/EN, доступность, e2e, комплект защиты |

Координатор ведёт backend/API, оркестрацию RAG, AI providers, shared contracts/SDK, инфраструктуру, интеграцию и общую оценку. Старые `TASK-*.md` оставлены как архив; актуальны `TEAM-*.md` и [AGENTS.md](AGENTS.md).

Репозиторий **публичный**: сделайте fork, клонируйте его, добавьте upstream `https://github.com/chinusoid/astana-compass.git`. Работайте в своей `team/...` ветке. Открывайте PR в upstream `main`, без самостоятельного merge. Публичность разрешает чтение и fork, но не даёт прямого push чужим аккаунтам. [Процесс интеграции](COORDINATION.md).

## API и ИИ

[HTTP endpoints и фабрики](docs/api/README.md), [канонические контракты](CONTRACTS.md), [архитектура](ARCHITECTURE.md).

Выбор `LLM_PROVIDER=openai` или `nvidia`, доступная вам `LLM_MODEL` и соответствующий серверный ключ подключают генератор. Он выбирает подтверждённые основания из ограниченного набора фактов. Код проверяет ограничения, бюджет времени и ссылки на доказательства. При недоступности модели работает явно обозначенное детерминированное объяснение. Наличие адаптера не означает, что ваш ключ и модель уже проверены.

[План собственного ИИ](docs/ai/TRAINING.md): лицензированный датасет → baseline/eval → retrieval/reranker fine-tuning или LoRA → повторная оценка. RAG не является обучением весов. NVIDIA inference API сам по себе не предоставляет GPU для обучения.

## До полноценного продукта

Нужны реальные данные и провайдеры трёх команд, live-интеграция, интерфейс, проверка качества на отложенных сценариях, публичное развёртывание и защита. Offline fixtures не показываются как реальные достопримечательности. Маршруты по прямой не выдаются за рассчитанные пешеходные пути. Feedback сейчас хранится только в ограниченной памяти процесса и не используется автоматически для обучения.

Лицензия кода ещё не выбрана владельцем; источники данных сохраняют свои условия и атрибуцию. Исходный документ хакатона, секреты, пользовательские координаты и большие дампы не публикуются.
