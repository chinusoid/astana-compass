# Astana Compass

Городской ИИ-помощник для Астаны: рекомендации с источниками, прогулки под доступное время и ответы RU / KK / EN.

**Текущий результат:** многостраничное веб-приложение с 3D-картой Астаны, выбором старта нажатием, прогулками, избранным, компаниями и событиями. ИИ-адаптеры OpenAI/NVIDIA разбирают запрос и составляют объяснения по проверяемым данным. Друзья и компании до 5 человек получают общий маршрут, чат, фотографии и добровольный обмен точкой на карте. Интерфейс адаптирован к компьютеру и телефону, поддерживает RU / KK / EN.

Доступны **300 реальных POI из OpenStreetMap**, отдельный автоматизированный импорт и локальный поиск BM25 со словарём RU/KK/EN. Это ограниченный snapshot, не полный каталог Астаны: описание есть у 1 места, часы работы — у 86; неизвестные удобства остаются неизвестными. [Происхождение и покрытие данных](docs/data/README.md), [источник и лицензия ODbL 1.0](data/samples/README.md).

**Режим по умолчанию остаётся `fixture` с тремя синтетическими POI**; реальные данные включаются явно через `ASTANA_MODE=live` и `ASTANA_POI_PATH`. Географическая подложка OpenFreeMap / OpenStreetMap не определяет режим каталога. Поиск лексический: semantic embeddings и обученная собственная модель не подключены. Hosted OpenAI/NVIDIA, реальные маршруты и пробки требуют отдельной настройки и проверки; публичный deployment отсутствует.

## Запуск

На **Windows / PowerShell 7+** установите uv 0.13.1, Python 3.12, Node.js 24.19.0 и pnpm 11.25.0, затем из корня:

```powershell
pwsh -NoProfile -File .\scripts\dev.ps1 -Mode fixture -LlmProvider none
```

API и web запускаются вместе; Ctrl+C останавливает только созданные launcher процессы. Для готового реального snapshot:

```powershell
$env:ASTANA_POI_PATH = (Resolve-Path '.\data\samples\astana-osm.json').Path
pwsh -NoProfile -File .\scripts\dev.ps1 -Mode live -LlmProvider none
```

[Windows: параметры, env-файл, импорт и проверки](docs/operations/WINDOWS.md). Полный локальный набор — `pwsh -NoProfile -File .\scripts\check.ps1`; browser E2E, live-provider smoke и remote CI проверяются отдельно.

Ниже — команды для POSIX shell; Windows-переменные окружения задаются по инструкции выше.

Установите [uv](https://docs.astral.sh/uv/getting-started/installation/), затем из корня:

```sh
uv sync --locked --all-packages
ASTANA_MODE=fixture LLM_PROVIDER=none uv run --locked uvicorn astana_api.app:create_app --factory --host 127.0.0.1 --port 8000 --no-access-log
```

Для пользовательского интерфейса установите Node.js 24.19.0 и pnpm 11.25.0, затем во втором терминале из корня репозитория:

```sh
cd apps/web
pnpm install --frozen-lockfile
ASTANA_ALLOW_FIXTURES=true pnpm dev
```

Откройте **`http://127.0.0.1:3000`**. На карте выберите старт нажатием и перейдите в «Прогулка». Для проверки synthetic-каталога используйте район `51.090, 71.420`, 90 минут и возврат (ручной ввод спрятан в раскрывающемся блоке). Выберите 1–3 места и рассчитайте маршрут. Настройки и production build описаны в [apps/web/README.md](apps/web/README.md).

В **`http://127.0.0.1:8000/sandbox`** остаётся технический экран backend, а в `/docs` — Swagger. Если порт API занят, замените `8000` на `18080` в команде запуска и задайте frontend `ASTANA_API_URL=http://127.0.0.1:18080`.

[Инструкция по тестированию и ожидаемые результаты](docs/operations/TESTING.md). Быстрая проверка работающего сервера:

```sh
uv run python scripts/smoke.py --base-url http://127.0.0.1:8000
```

`.env.example` содержит только имена настроек; экспортируйте свои значения в окружение процесса. Не публикуйте ключи в чатах, PR или frontend.

```sh
uv run pytest
uv run python verify_contracts.py
uv run python scripts/generate_contracts.py --check
uv run ruff check .
```

Docker и CI: [инфраструктура](infra/), [операции](docs/operations/).

## Три основных агента

Передайте каждому отдельный файл целиком. Каждый агент может привлекать своих subagents внутри своей области.

| Команда | Полное задание | Результат |
|---|---|---|
| 01 | [Данные и поиск](TEAM-01-DATA-SEARCH.md) | Автосбор реальных POI, provenance, hybrid retrieval, embeddings/reranking, датасет |
| 02 | [Контекст и маршруты](TEAM-02-CONTEXT-ROUTES.md) | Пешие маршруты, время, расписания, погода, честные unknown/fallback |
| 03 | [Интерфейс и UX](TEAM-03-FRONTEND-UX.md) | Next.js, карта, RU/KK/EN, доступность, e2e, комплект защиты |

Координатор ведёт backend/API, оркестрацию RAG, AI providers, shared contracts/SDK, инфраструктуру, интеграцию и общую оценку. Старые `TASK-*.md` оставлены как архив; актуальны `TEAM-*.md` и [AGENTS.md](AGENTS.md).

Репозиторий **публичный**: сделайте fork, клонируйте его, добавьте upstream `https://github.com/chinusoid/astana-compass.git`. Работайте в своей `team/...` ветке. Открывайте PR в upstream `main`, без самостоятельного merge. Публичность разрешает чтение и fork, но не даёт прямого push чужим аккаунтам. [Процесс интеграции](COORDINATION.md).

## API и ИИ

[HTTP endpoints и фабрики](docs/api/README.md), [канонические контракты](CONTRACTS.md), [архитектура](ARCHITECTURE.md).

Выбор `LLM_PROVIDER=openai` или `nvidia`, доступная вам `LLM_MODEL` и соответствующий серверный ключ подключают разбор намерения и генератор объяснений. Кнопка «Разобрать запрос» передаёт модели текст запроса и язык; координаты, чат и фото не добавляются к этому запросу. Пользователь проверяет предложенные условия перед применением. Генератор объяснений выбирает подтверждённые основания из ограниченного набора фактов. Код проверяет ограничения, бюджет времени и ссылки на доказательства. При недоступности модели работает явно обозначенное детерминированное объяснение. Наличие адаптера не означает, что ваш ключ и модель уже проверены.

[Разбор пяти пользовательских сценариев и границы доверия](docs/ai/intent.md). Время до вылета требует уточнения: сервис не считает его целиком доступным для прогулки.

[План собственного ИИ](docs/ai/TRAINING.md): лицензированный датасет → baseline/eval → retrieval/reranker fine-tuning или LoRA → повторная оценка. RAG не является обучением весов. NVIDIA inference API сам по себе не предоставляет GPU для обучения.

В live-режиме `astana_city_data` читает проверяемый локальный snapshot с provenance, а `astana_retrieval` ранжирует ограниченную выборку ближайших мест по BM25 и словарю. Сбор выполняется отдельной CLI, не при пользовательском запросе. [Данные и повторный импорт](packages/city_data/README.md), [ранжирование и ограничения](packages/retrieval/README.md), [оценка качества](docs/retrieval/QUALITY.md). Метрики на synthetic-корпусе не являются измерением полезности всех реальных городских рекомендаций.

## Совместная прогулка и карта

- `/`, `/walk`, `/saved`, `/party`, `/events`, `/about` — отдельные страницы с общим состоянием планирования в памяти вкладки.
- OpenFreeMap работает без ключа; 2D/3D переключаются на карте. Декоративное движение подписано как симуляция и не представляет пробки. `TOMTOM_API_KEY` на backend включает отдельный запрос реального дорожного потока; плотность нарисованных машин условная и не является подсчётом автомобилей.
- Гостевые профили, дружба, компании и чат живут в памяти одного backend-процесса до 24 часов. Вступление требует принятия приглашения, компания — до 5 человек. Минимальный бюджет участников и обязательные условия учитываются совместно.
- Фото уменьшается и очищается от метаданных перед отдельной отправкой. Точка местоположения отправляется только по кнопке на 15 минут, её можно удалить. Фонового трекинга нет.
- Пользовательские события имеют точку и время, видны на карте и явно помечены как непроверенные объявления. Они не становятся подтверждёнными POI автоматически.
- Для телефона нужен доступный HTTPS-адрес: `127.0.0.1` на телефоне относится к самому телефону. Manifest поддерживает установку веб-приложения в совместимом браузере; офлайн-режим, отдельные нативные приложения и постоянные аккаунты не заявляются.

[Сценарий демонстрации](docs/ux/judging-demo.md), [провайдеры карты](docs/ux/maps.md), [документация интерфейса](apps/web/README.md).

## До полноценного продукта

Нужны расширение источников и подтверждённых описаний/удобств, независимая оценка поиска на реальных RU/KK/EN-сценариях, проверка live-провайдеров, публичное развёртывание и комплект защиты. Слайды на 5–7 минут и опубликованное YouTube-демо пока не подтверждены. [Сверка официальных требований и пожеланий владельца](docs/operations/REQUIREMENTS-CHECK.md) отделяет реализацию от незавершённых пунктов. Offline fixtures не показываются как реальные достопримечательности. Маршруты по прямой не выдаются за рассчитанные пешеходные пути. Feedback хранится только в ограниченной памяти процесса и не используется автоматически для обучения.

Лицензия кода ещё не выбрана владельцем. Включённый OSM sample и его raw-cache распространяются по [ODbL 1.0](data/samples/README.md), © OpenStreetMap contributors; это отдельная лицензия данных. Исходный документ хакатона, секреты, пользовательские координаты и большие дампы не публикуются.
